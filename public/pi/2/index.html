Pinto Improvements

PI-2: Remove Anti Lambda to Lambda Convert

Executed on November 27, 2024 at 21:11 UTC.

Summary

Remove the Anti Lambda to Lambda (AL2L) Convert functionality from the Silo to prevent users from removing each other's Rain Stalk.

  • Implementation PR
  • Implementation Commit: c2077d53a84646f1fa2f09099547a628b6c2f590

Background

Before this upgrade, AL2L Converts allowed any Farmer to Convert another Farmer's Deposit in order to decrease its Pinto-Denominated Value (PDV) if the current PDV of the Deposit (i.e., the PDV per token * the number of tokens) is less than the recorded PDV (i.e., the PDV stored onchain, which is used by the protocol to determine how many Stalk and Seeds to award the Deposit).

The ability to decrease a Deposit's PDV is necessary because as the value in liquidity pools changes due to changes in the price of the non-Pinto asset in the liquidity pool and/or the ratio of the assets in the liquidity pool changes, it is possible for the PDV of the Deposit to decrease substantially. By enabling anyone to decrease the PDV associated with a Deposit that is recorded by the protocol, the instances where the protocol is awarding excess Stalk and Seeds to a Deposit beyond the current value the Deposit is contributing to the protocol can be drastically reduced without requiring the protocol to regularly check the PDV of each Deposit, which would be expensive. Of course, there is no incentive for a Farmer to decrease their own PDV. Thus, the AL2L Convert is callable by any user on eligible Deposits that had completed Germination.

Problem

AL2L Converts had a bug in their implementation that would result in a loss of the Rain Stalk associated with the Deposit while it's Raining and/or Flooding. Rain Stalk is the snapshot of Stalk holdings taken each time it begins to Rain, which determines pro rata ownership of the proceeds from the Flood sale. While an AL2L Convert should decrease the Rain Stalk associated with a Deposit in the instance where its PDV is decreased, the AL2L Convert erroneously removed Rain Stalk during withdrawal without restoring the Farmer's Rain Stalk snapshot when the Deposit was recreated.

Solution

Remove AL2L Converts until a fix can be implemented to allow Farmers to retain the appropriate number of Rain Stalk during Converts.

Rationale

Temporarily removing AL2L Converts prevents another Farmer from triggering the erroneous Rain Stalk removal while a fix is developed. The tradeoff is that AL2L Converts cannot reduce overstated Deposit PDV during this period.
